# 英単語マスター（中学版シス単 英単語アプリ）

例文と音声で英単語・熟語を覚える、スマホ向けの学習アプリです。
例文の音声を聞き、意味の 4 択 → 聞き取り穴埋め → つづり入力 と、間隔をあけた復習で覚えていきます。

## このアプリについて

- **家庭内の学習用**です。お子さんが自分の本（中学版システム英単語〈改訂版〉）と一緒に使うことを想定しています。
- **教材データ（音声・英文・和訳・単語の一覧）は、このリポジトリにも公開ページにも含まれていません。**
  教材データは出版社の著作物なので、保護者の方が PC で「データパック」（zip ファイル）を作り、
  スマホに直接取り込んで使います。データパックはインターネット上に置かないでください。
- アプリ本体（画面のしくみ）だけを GitHub Pages で公開しています。一度開けば、電波がなくても起動できます。

## 1. PC でデータパックを作る

### 1-1. 用意するもの

| もの | 説明 |
|---|---|
| Windows の PC | 作業はコマンドプロンプト（または PowerShell）で行います |
| Python 3 | `C:\Users\<ユーザー名>\.venvs\syswords\` のような仮想環境に、numpy と faster-whisper を入れておく |
| ffmpeg | `winget install ffmpeg` で入れる。`ffmpeg -version` で確認できれば OK |
| 音声ファイル | 本の付属音声（mp3 562 本）を `data\private\audio\` にコピーしておく |

- 以下のコマンドは、このフォルダ（`README.md` があるフォルダ）で実行します。
- 文字化けを防ぐため、最初に `set PYTHONUTF8=1`（PowerShell なら `$env:PYTHONUTF8 = "1"`）を実行しておきます。
- `data\private\` に置いたものは Git の対象外です（GitHub には上がりません）。

### 1-2. スクリプトの役割と実行順

| 順 | スクリプト | やること | 主な出力（すべて `data\private\`） |
|---|---|---|---|
| 1 | `tools\segment.py` | 音声の中の「英語 1・日本語・英語 2・英語 3」の区切りを求める（2 の中でも自動で使われる。単独では確認用） | `segments.json` |
| 2 | `tools\transcribe.py` | 区切りごとに文字起こしをして、例文の一覧を作る。あやしい文には「要確認」の印を付ける | `sentences.json`、`review.csv` |
| 3 | `tools\candidates.py` | 例文ごとに「初めて出てくる語」を一覧にする（見出し語選びの下準備） | `candidates.json` |
| 4 | （見出し語の抽出） | `tools\extract_guide.md` のルールで、例文ごとに覚える語・熟語を選ぶ | `words_parts\part*.json` |
| 5 | `tools\merge_words.py` | 4 の結果を 1 つにまとめ、番号（w0001〜）を振る | `words.json` |
| 6 | `tools\apply_review.py` | 点検で出た修正案を 4 の結果に反映する（必要なときだけ。反映後に 5 をやり直す） | `words_parts_reviewed\` |
| 7 | `tools\csv_io.py` | `words.json` ⇔ `words.csv`（Excel で確認・修正するため。3 章を参照） | `words.csv` |
| 8 | `tools\build_pack.py` | 例文・単語・音声をまとめて、データパック（zip）を作る | `syswords-pack.zip` |

各スクリプトの細かい使い方は、ファイルの先頭に書いてあります。

### 1-3. データパックを作るコマンド（8 の例）

```bat
set PYTHONUTF8=1
C:\Users\<ユーザー名>\.venvs\syswords\Scripts\python.exe tools\build_pack.py ^
    --sentences data\private\sentences.json ^
    --words data\private\words.json ^
    --audio-dir data\private\audio ^
    --out data\private\syswords-pack.zip ^
    --title "英単語マスター"
```

- 作る前に中身を検査します。問題があれば一覧を表示して中止します（zip は作られません）。
- 作ったあと zip を開き直し、件数が合っているかを確かめて表示します。
- すでに `syswords-pack.zip` があるときは、古いほうを `syswords-pack.zip.bak-日時` の名前で残します。
- できあがる zip は約 80MB です。

## 2. データパックをスマホに入れる

### はじめに：ホーム画面に追加してから取り込む（特に iPhone）

iPhone では、**Safari で開いたアプリと、ホーム画面に追加したアプリは、保存場所が別々**です。
Safari で取り込んでからホーム画面に追加すると、ホーム画面のアプリには何も入っていない状態になります。
**先に「4. ホーム画面に追加する」を済ませ、ホーム画面のアイコンから開いて取り込んでください。**
（Android の Chrome は、どちらから開いても同じ保存場所です。）

### 2-1. iPhone（「ファイル」App 経由）

**① PC から iPhone の「ファイル」に zip を保存する**（どちらか 1 つ）

- **AirDrop（Mac がある場合）**
  1. Mac で `syswords-pack.zip` を右クリック →「共有」→「AirDrop」→ お子さんの iPhone を選ぶ。
  2. iPhone に「AirDrop」の確認が出たら「受け入れる」。
  3. 開くアプリを聞かれたら「ファイル」を選び、「このiPhone内」→ 好きなフォルダ（例：「ダウンロード」）→「保存」。
- **iCloud Drive（Windows の PC の場合）**
  1. Windows に「iCloud for Windows」（Microsoft Store から入手）を入れ、iPhone と同じ Apple ID でサインインする。
  2. エクスプローラーの左側にある「iCloud Drive」を開き、`syswords-pack.zip` をドラッグしてコピーする。
  3. コピーが終わる（雲のマークが消える）まで待つ。
  4. iPhone で「ファイル」App を開き、「ブラウズ」→「iCloud Drive」に zip があることを確認する。
     ファイル名の横に雲のマークがあるときは、一度タップしてダウンロードしておく。
- （ほかに、ブラウザ版 iCloud（icloud.com）の「iCloud Drive」にアップロードする方法もあります）

> 注意：zip をメールや LINE、公開されたクラウドの共有リンクで送らないでください（教材データが外に出てしまうため）。

**② アプリで取り込む**

1. ホーム画面の「英単語マスター」のアイコンをタップして開く。
2. 「はじめに」の画面で「**データパックを選ぶ**」をタップする。
3. 「ファイル」の画面が開くので、①で保存した場所（「このiPhone内」や「iCloud Drive」）から `syswords-pack.zip` をタップする。
4. 進み具合のバーが出ます。終わるまで（1〜2 分ほど）アプリを閉じず、画面を消さずに待つ。
5. ホーム画面（「今日の学習」）が表示されたら完了です。取り込みは最初の 1 回だけです。
6. 取り込みが終わったら、「ファイル」に残っている zip は消してもかまいません（容量を空けたいとき）。

### 2-2. Android（「ダウンロード」フォルダ経由）

**① PC から Android の「ダウンロード」フォルダに zip を保存する**（どちらか 1 つ）

- **USB ケーブル**
  1. スマホと PC をケーブルでつなぐ。
  2. スマホに出る「USB の設定」（または通知の「この端末を USB で充電中」）をタップし、「ファイル転送」を選ぶ。
  3. PC のエクスプローラーにスマホの名前が出るので、「内部共有ストレージ」→「Download」を開く。
  4. `syswords-pack.zip` をそこへコピーする。終わったらケーブルを抜く。
- **Google ドライブ（自分のアカウントの中だけで使う）**
  1. PC のブラウザで Google ドライブを開き、`syswords-pack.zip` をアップロードする（**共有の設定はしない**）。
  2. スマホの「ドライブ」アプリで同じアカウントを開き、zip の「︙」→「ダウンロード」。
  3. 「ダウンロード」フォルダに保存されます。

**② アプリで取り込む**

1. Chrome（またはホーム画面のアイコン）で「英単語マスター」を開く。
2. 「**データパックを選ぶ**」をタップする。
3. ファイルを選ぶ画面が開くので、左上の「≡」→「ダウンロード」（機種により「Download」）を選び、`syswords-pack.zip` をタップする。
   （「写真や動画を選ぶ」画面が出たときは、「ファイル」や「ブラウズ」を選ぶと切り替わります）
4. 進み具合のバーが終わるまで、アプリを閉じずに待つ。
5. ホーム画面（「今日の学習」）が表示されたら完了です。

### 2-3. データパックを作り直したとき（入れ直し）

単語を直してデータパックを作り直したら、新しい zip を同じ方法でスマホに保存し、
アプリの「設定」→「**データパックを入れ直す**」で選びます。**学習の記録は消えません。**

## 3. 単語の照合（本と照らし合わせる）

単語・熟語の一覧は、例文から自動で作った候補です。意味や見出し語がまちがっていることがあります。
アプリでは、まだ本と照合していない語に小さく「未確認」の印が出ます。

1. **CSV を作る**
   ```bat
   C:\Users\<ユーザー名>\.venvs\syswords\Scripts\python.exe tools\csv_io.py to-csv ^
       --words data\private\words.json --sentences data\private\sentences.json ^
       --csv data\private\words.csv
   ```
2. **Excel で開いて、本と照らし合わせて直す**（`data\private\words.csv` をダブルクリック）
   - 直す：そのまま書き換える。確認が済んだ行は「確認済み」に `○` を入れる。
   - 足す：一番下に行を追加し、ID は空欄のままにする。
   - 消す：行ごと削除する。
   - 「例文番号」は `12` や `12;40` のように `;` で区切る。最初の番号が、出題に使う代表の例文。
   - 「参照:」で始まる列は見るためだけの列です（書き換えても取り込まれません）。
   - 保存するときは「**CSV UTF-8（コンマ区切り）**」を選ぶ。
3. **words.json に戻す**（元の words.json は日時つきの `.bak` で残ります）
   ```bat
   C:\Users\<ユーザー名>\.venvs\syswords\Scripts\python.exe tools\csv_io.py to-json ^
       --csv data\private\words.csv --sentences data\private\sentences.json ^
       --words data\private\words.json
   ```
4. **データパックを作り直す**（1-3 のコマンド）→ スマホで入れ直す（2-3）。

## 4. ホーム画面に追加する

ホーム画面に追加すると、ふつうのアプリのようにアイコンから開け、画面も広く使えます。電波がなくても起動できます。

### iPhone（Safari）

1. **Safari** でアプリのページ（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を開く。
   （Chrome など、ほかのブラウザでは追加できないことがあります。Safari を使ってください）
2. 画面下（または上）の **共有ボタン**（四角から上向きの矢印が出ているマーク）をタップする。
3. 一覧を下にスクロールし、「**ホーム画面に追加**」をタップする。
4. 名前が「英単語マスター」になっていることを確認して、右上の「**追加**」をタップする。
5. ホーム画面に「単」のアイコンが出ます。**以後はこのアイコンから開いてください。**

### Android（Chrome）

1. **Chrome** でアプリのページを開く。
2. 右上の **︙（メニュー）** をタップする。
3. 「**アプリをインストール**」または「**ホーム画面に追加**」をタップする（Chrome の版によって名前が違います）。
4. 確認が出たら「インストール」（または「追加」）をタップする。
5. ホーム画面（またはアプリの一覧）に「単」のアイコンが出ます。

### 新しい版があるとき

アプリを更新すると、画面に「新しい版があります。再読み込み」と出ます。
学習の区切りのよいところでボタンを押すと、新しい版に切り替わります（学習の記録は消えません）。

## 5. 学習の記録について

- 学習の記録（どの語を覚えたか、次にいつ復習するか、連続学習日数など）は、**その端末の中だけ**に保存されます。
  インターネット上には送られません。別の端末とは共有されません。
- **データパックの入れ直しでは消えません。**
- 次のときは記録が**消えます**：
  - ホーム画面のアプリを削除したとき
  - ブラウザの「履歴とWebサイトデータを消去」（iPhone の設定 → Safari）や「閲覧データを削除」（Chrome）をしたとき
  - 機種変更したとき
- プライベートブラウズ（シークレットモード）で開くと、記録が残りません（画面に注意が出ます）。
- iPhone では、ホーム画面に追加せず Safari だけで使っていると、しばらく使わない間にブラウザが保存データを消すことがあります（要確認：Safari の仕様による）。ホーム画面に追加して使うことをおすすめします。

## 6. 困ったとき

| 困ったこと | 確かめること・対処 |
|---|---|
| 取り込みで「容量が足りません」と出る | スマホの空き容量が足りません。約 200MB 以上空けてから、もう一度選んでください（設定 → 一般 → iPhone ストレージ／Android は 設定 → ストレージ）。取り込み後は「ファイル」や「ダウンロード」の zip を消してかまいません。 |
| 取り込みで「形式が違う」「壊れている」と出る | zip のコピーが途中で止まった可能性があります。PC からもう一度コピーし直してください。それでもだめなら、PC で `build_pack.py` を実行し直してください。 |
| 「データパックを選ぶ」で zip が見つからない | iPhone：「ファイル」App で zip がある場所（「このiPhone内」「iCloud Drive」）を確認。雲のマークがあればタップしてダウンロード。Android：「ダウンロード」フォルダにあるか確認。 |
| 音が出ない | iPhone は**本体左側のマナーモード（消音）スイッチ**をオフにする（オレンジ色が見えていたら消音）。音量ボタンで音量を上げる。Bluetooth イヤホンのつながり先も確認。 |
| 単語だけの発音が出ない／機械の声が変 | 単語だけの発音は端末の読み上げ機能を使っています。iPhone：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語 の声をダウンロードすると改善することがあります。 |
| ホーム画面のアプリにデータが入っていない（iPhone） | Safari で取り込んだデータは、ホーム画面のアプリからは見えません。ホーム画面のアイコンから開いて、もう一度取り込んでください。 |
| 画面が古いまま／動きがおかしい | 電波のある場所で一度アプリを閉じて開き直す。「新しい版があります」が出たら「再読み込み」を押す。 |
| 記録が消えた | 「5. 学習の記録について」の「消えるとき」に当てはまらないか確認してください。 |

## 7. 開発者向けメモ

- プロジェクトのルールは `CLAUDE.md`、データパックの形式は `tools\PACK_FORMAT.md`、JS の関数の一覧は `js\API.md` を参照。
- **教材の文章（英文・和訳）や音声を、コード・テスト・コミットメッセージ・この README に書かない。** テストは自作のダミーデータを使う。
- 公開前に `git ls-files` で、mp3・json・zip などの教材データが含まれていないことを確認する。

### テストの実行

```bat
:: Python（データ作成ツール）
C:\Users\<ユーザー名>\.venvs\syswords\Scripts\python.exe -m unittest discover -s tests

:: JavaScript（学習ロジック・PWA の設定）
node --test tests\

:: データパックの取り込み（IndexedDB の代役で確認）
node tests\db_node_test.mjs
```

### PWA（オフライン起動）

- `manifest.webmanifest`：アプリ名・色・アイコン。`start_url` と `scope` は `./`（GitHub Pages のサブパスで動くよう相対）。
- `sw.js`：アプリ本体をキャッシュする Service Worker。**教材データは扱わない**（データパックは IndexedDB に入り、Service Worker を通らない）。
  - 取得の方針は「ネットワーク優先＋失敗・時間切れのときはキャッシュ」。理由は `sw.js` の先頭に記載。
  - **js\modes\ などにファイルを足したら**、`sw.js` の `APP_FILES` に足し、`CACHE_VERSION` を 1 つ上げる。
    入れ忘れは `node --test tests\pwa.test.mjs` で検出できる。
- `js\pwa.js`：Service Worker の登録と、新しい版の知らせ（`onUpdate(callback)`）。
- アイコンは `tools\make_icons.py` で作る（Python 標準ライブラリのみ）。
  ```bat
  C:\Users\<ユーザー名>\.venvs\syswords\Scripts\python.exe tools\make_icons.py --out-dir icons --check
  ```
